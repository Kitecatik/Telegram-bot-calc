# Calculator Telegram bot
Telegram-бот-калькулятор с поддержкой базовых арифметических действий, FSM состояний и безопасным парсингом пользовательского ввода.
# Как установить и запустить бота?
Для установки бота для систем Unix, пропишите команду:
```
git clone https://github.com/Kitecatik/Telegram-bot-calc.git
```

Затем введите команду в директории проекта 
``` 
python3 Main.py
```
